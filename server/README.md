# Todo App backend (optional)

A small **FastAPI + SQLite** service that persists tasks and categories, so the
app can keep them somewhere other than the browser.

> [!IMPORTANT]
> The backend is **optional and not deployed**. Netlify publishes static assets
> only, and no Python process runs there. The app stays fully functional — including
> offline — with this server stopped, missing or unreachable: `localStorage`
> remains the source of truth for the UI, and the server is a background-synced
> replica. Sync failures are logged to the console and never shown as a toast.

It is **single-user**: there is no authentication, no `user_id` column and no
authorization anywhere. Run it on your own machine.

## Requirements

- Python 3.10+
- [uv](https://docs.astral.sh/uv/) (or plain `pip` + `venv`)

## Running

```bash
cd server
uv venv
uv pip install -e ".[dev]"
uv run uvicorn app.main:app --reload --port 8000
```

Swagger UI: <http://localhost:8000/docs>

With plain pip:

```bash
cd server
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

The frontend's dev server proxies `/api` to `http://localhost:8000`, so
`npm run dev` needs no extra configuration. Serving on another port? Point the
proxy at it with `VITE_API_PROXY_TARGET=http://localhost:9000 npm run dev`. See
the root [README](../README.md) for that and for `VITE_API_URL`.

> [!WARNING]
> The client mirrors whatever `localStorage` holds, so logging out of the app
> (which resets the state to the default user) is synced like any other change:
> every task is deleted from the server and the default categories are restored.
> Stop the server first if you want to keep its contents.

## Tests

```bash
cd server
uv run pytest
```

The suite covers CRUD for both entities, the multi-category link, the
"delete a category → it is unlinked, the task survives" scenario, the datetime
round-trip, and persistence across a restart.

## Configuration

| Variable            | Default                                                              | Meaning                                                                        |
| ------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `TODO_DB_PATH`      | `server/todo.db`                                                     | SQLite database file. Resolved relative to the `server/` package, not the CWD. |
| `TODO_CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173,https://localhost:5173` | Comma-separated allowed origins. The `https` entry covers `npm run dev:host`.  |

The database file is gitignored. Tables are created on startup — there is no
migration system, so if you change a model, delete `todo.db` and start again.

## API

All routes are unauthenticated and live under `/api`. Dates are ISO 8601 with an
explicit `Z` (UTC) in every response; the field names match `Task` and
`Category` in [`src/types/user.ts`](../src/types/user.ts) one-to-one.

| Method   | Path                   | Notes                                                                                                                                  |
| -------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`    | `/api/tasks`           |                                                                                                                                        |
| `POST`   | `/api/tasks`           | `201`. The `id` is generated by the client and used verbatim; `409` if it already exists. `category` is a list of `{ id }` references. |
| `GET`    | `/api/tasks/{id}`      | `404` if absent                                                                                                                        |
| `PATCH`  | `/api/tasks/{id}`      | Partial. `category` omitted leaves the links untouched; `category` present (even `[]`) replaces the whole set.                         |
| `DELETE` | `/api/tasks/{id}`      | `204`                                                                                                                                  |
| `GET`    | `/api/categories`      |                                                                                                                                        |
| `POST`   | `/api/categories`      | `201`, client-supplied `id`, `409` on duplicate                                                                                        |
| `GET`    | `/api/categories/{id}` | `404` if absent                                                                                                                        |
| `PATCH`  | `/api/categories/{id}` | Partial                                                                                                                                |
| `DELETE` | `/api/categories/{id}` | `204`. Unlinks the category from its tasks; **the tasks themselves are not deleted.**                                                  |

### A note on datetimes

SQLite has no timezone-aware column type: an aware `datetime` goes in and a naive
one comes back. In the browser, `new Date("2026-01-01T10:00:00")` parses as
_local_ time, which would quietly skew the last-write-wins comparison on
`lastSave` by the client's UTC offset. The server therefore normalises every
incoming datetime to naive UTC and serialises it back with an explicit `Z`. See
`app/datetime_utils.py`.
